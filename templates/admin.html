Developer Documentation
1
Create a Project
Use the Add New Project form above to register your app. Enter a unique Project ID (lowercase, underscores only). An API key is auto-generated if left blank. Copy and save your API key immediately — it is shown only once.
2
Authenticate Your Requests
Every API call requires your Project ID in the URL path and your API Key in the x-api-key header.
# All requests follow this pattern:
curl -H "x-api-key: YOUR_API_KEY" \
  {{ base_url }}/{project_id}/{operation}/{key}
3
Store & Retrieve Data
Use SET to store a value and GET to retrieve it. Values can be strings, numbers, JSON objects, or arrays. Optionally set a TTL (in seconds) for auto-expiry.
# SET a key (with optional TTL)
curl -X POST {{ base_url }}/my_app/set/username \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"value": "john_doe", "ttl": 3600}'

# GET a key
curl {{ base_url }}/my_app/get/username \
  -H "x-api-key: YOUR_API_KEY"

# Response:
{"key": "username", "value": "john_doe", "exists": true}
4
Use in Your Application
Integrate with any language or framework using standard HTTP requests.
# Python
import requests

BASE = "{{ base_url }}/my_app"
HEADERS = {"x-api-key": "YOUR_API_KEY"}

# Set
requests.post(f"{BASE}/set/score",
  headers=HEADERS, json={"value": 42, "ttl": 7200})

# Get
r = requests.get(f"{BASE}/get/score", headers=HEADERS)
print(r.json()["value"]) # 42
// JavaScript (fetch)
const BASE = "{{ base_url }}/my_app";
const HEADERS = {"x-api-key": "YOUR_API_KEY"};

// Set
await fetch(`${BASE}/set/score`, {
  method: "POST",
  headers: {...HEADERS, "Content-Type": "application/json"},
  body: JSON.stringify({value: 42, ttl: 7200})
});

// Get
const res = await fetch(`${BASE}/get/score`, {headers: HEADERS});
const data = await res.json();
console.log(data.value); // 42
API Reference
All endpoints require the x-api-key header. Replace {pid} with your Project ID and {key} with your Redis key.
String Operations
GET /{pid}/get/{key}
Get a value by key
POST /{pid}/set/{key}
Set a value · Body: {"value", "ttl?"}
DEL /{pid}/delete/{key}
Delete a key
POST /{pid}/incr/{key}
Increment · Body: {"by": 1}
POST /{pid}/mset
Set multiple · Body: {"pairs", "ttl?"}
POST /{pid}/mget
Get multiple · Body: ["key1","key2"]
Key Utilities
POST /{pid}/expire/{key}
Set TTL · Body: {"ttl": seconds}
GET /{pid}/ttl/{key}
Get remaining TTL
GET /{pid}/keys
List all keys in project
DEL /{pid}/flush
Delete all keys in project
List Operations
POST /{pid}/lpush/{key}
Push left · Body: {"values": [...]}
POST /{pid}/rpush/{key}
Push right · Body: {"values": [...]}
GET /{pid}/lrange/{key}
Get range · Query: ?start=0&end=-1
DEL /{pid}/lpop/{key}
Pop from left
DEL /{pid}/rpop/{key}
Pop from right
Hash Operations
POST /{pid}/hset/{key}
Set fields · Body: {"mapping": {...}}
GET /{pid}/hget/{key}/{field}
Get a single hash field
GET /{pid}/hgetall/{key}
Get all fields and values
DEL /{pid}/hdel/{key}/{field}
Delete a hash field
Health & Status
GET /health
Check API & Redis status
GET /keep-alive
Keep-alive ping with Redis check
