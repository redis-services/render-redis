Basics

Base URL
{{ example_base }} {{ copy_button(example_base, 'Base URL') }}

Every path below is relative to this. Your project ID is part of the URL, so there is no connection string and no host to configure.

Authentication

Send your key in the x-api-key header on every request. A missing header is a 422; a wrong key is a 401.

curl {{ example_base }}/get/hello \ -H "x-api-key: $CENTRAL_KEY"
Values

Values are stored as JSON when they parse as JSON, and as raw strings otherwise. Reads reverse this, so {"a": 1} comes back as an object, not a string. Numbers, booleans, arrays, and nested objects all round-trip.

Namespacing

Keys are stored internally as {{ example_project }}:your_key. You never write the prefix and never see it — but it means two projects can both use session:1 without colliding.

TTL

Pass ttl in seconds on write, or call /expire later. Keys without a TTL live until deleted. /ttl returns -1 for no expiry and -2 if the key does not exist.

Listing and clearing

Listing is cursor-based. Pass the cursor from each response back on the next call until done is true. A cursor of 0 with done: false does not mean you are finished — always check done.
{{ endpoint('GET', '/keys?pattern=*&cursor=0&limit=200', 'Key names only. Patterns are Redis globs, scoped to your project.', '', '{\n "project": "' ~ example_project ~ '",\n "keys": ["cart:42", "cart:43"],\n "count": 2,\n "cursor": 0,\n "done": true\n}') }} {{ endpoint('GET', '/scan?pattern=*&cursor=0&limit=50', 'Like /keys, but with type, TTL, and size for each key.', '', '{\n "keys": [\n {"key": "cart:42", "type": "string", "ttl": 3540, "size": 248}\n ],\n "cursor": 0,\n "done": true\n}') }} {{ endpoint('DELETE', '/flush', 'Delete every key in this project. Errors

CodeMeaning
401The key is wrong, revoked, or belongs to a different project.
404No such project. Check the project ID in your base URL.
409The operation doesn't fit the value — incr on something that isn't an integer.
422The request body or headers didn't validate. A missing x-api-key lands here.
503Redis is unreachable. Retry with backoff.

Errors carry a detail field:

{ "detail": "Invalid API key" }
